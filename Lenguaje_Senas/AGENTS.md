# Project conventions

- This project uses React, TypeScript, and Vite. Do not add Next.js APIs or files.
- Keep application components in `src/components`, shared state in `src/context`, helpers in `src/lib`, and imported assets in `src/assets`.
- Keep files served directly by the browser in `public`.
- Use pnpm for dependency management and scripts.
- Verify changes with `pnpm build`.
